# Mafia Camp

A video party game for 3 to 10 friends, built on [Anvil](https://anvil.works). Everyone joins one small-tile video call straight from the browser, gets a secret role, and plays Mafia (Werewolf) at Camp Moonlake: the Mafia strike at night, the camp argues it out on camera by day and votes someone onto the bus home.

## Features

- **No accounts.** Start a camp, share its 4-letter code or invite link (`…/#ABCD`), type a name, play. A reload keeps your seat and your role.
- **10-way video + voice, peer to peer.** Every browser connects directly to every other one with WebRTC. Anvil is the go-between: it passes each pair's one-time handshake notes (no outside signalling service). When a direct route is blocked (phones on mobile data, strict Wi-Fi), Cloudflare TURN relays the encrypted stream. Video is 320×240 at 15 fps, capped around 150–180 kbps per connection, so a full camp needs about 1.5 Mbps upload per person. Tested locally with 10 browsers: all 90 connections up in 4 seconds.
- **The call follows the game.** Each browser decides what it sends to whom (`RTCRtpSender.replaceTrack`):
  - lobby, role reveal, game over: everyone sees and hears everyone;
  - night: Campers go dark; the Mafia see and hear only each other (and the ghosts can watch them);
  - day: everyone alive is on camera;
  - ghosts (players who are out, and late joiners) talk only with other ghosts.
- **Roles:** the Mafia (1 for 3–5 players, 2 for 6–9, 3 for 10), Camp Nurse (protects one camper a night, not the same twice in a row), Ranger (investigates one camper a night), Campers, and an optional Prankster (7+, wins by getting voted out).
- **Phases:** roles → night → dawn (the news) → day (talk; "Ready to vote" with a majority skips ahead) → vote (open votes, live tallies on the tiles, ties and "skip" send nobody home) → verdict → … until the Campers or the Mafia win.
- **Host controls:** talk/night/vote times, reveal roles on death, Prankster on/off, skip ahead, send a player home, play again. If the host disappears, the longest-present player takes over.
- **Look:** the sky follows the game (dusk campfire, starry night, dawn, daylight), speaking glow on tiles, sleeping/ghost covers, phase chimes, confetti for the winners, a tent-under-the-moon icon and matching loading spinner. Phone first; desktop puts the panel beside the grid.
- Privacy & Terms from the shared Arkvital legal kit (camera/mic, peer-to-peer video, Cloudflare relay, 24-hour camp clean-up).

## How it's built

Native Anvil Forms (Python + HTML templates) around one JavaScript engine for the call:

```
client_code/startup.py   connects the engine to the server (mc.setup), Privacy & Terms, then the page for the address
client_code/router.py    "" / #home = Pages/Home; #ABCD (an invite link) = Home with the code filled in; #watch
client_code/mc.py        the engine seen from Python: the server bridge (game.mc_api), the callbacks it uses
                         (toast, confirm, view, entered, left, dock, copy), the roles
client_code/Layouts/Shell  the sky, the home page's header and footer (hidden in a camp)
client_code/Pages/       Home (start / join a camp), Room (the bar, the side panel, the story, the dock)
client_code/Panels/      the side panel per phase: Lobby, Roles, Night, News (dawn + verdict), Day, Vote, Over
client_code/Components/  VideoGrid (the engine's tiles), Notebook (the Ranger's findings), Tally (the vote count)
client_code/Items/       StoryEvent, Chip (a setting), CheckRow, TallyRow, RevealRow; Dialogs/Invite
server_code/game.py      every game rule: one callable mc_api(action, payload_json)
theme/assets/mc-engine.js  the engine: camera + mic, the WebRTC mesh, handshake and night routing, the 2 s poll, the phase
                         clock, the video tiles (pick / vote / remove), sounds, music, confetti
theme/assets/app.css     the design (sky themes per phase), the design kit, Anvil components' look
theme/assets/peerjs.min.js  PeerJS 1.5.2, served with the app
tools/                   check.py (validator, JS, assets, server tests), ui_test.py (the real app in the Anvil App
                         Server: a whole game with two test campers, phone width, accessibility, design)
```

Tables: `rooms` (code, host, phase + timer, settings, the whole game as one simpleObject) and `players` (room, secret token, public pid, name, seat, call id, mic/cam state, last seen), and `signals` (one-time call set-up notes between two players, deleted when read or after 2 minutes). Camps untouched for 24 hours are deleted when a new camp starts.

## Opening it in Anvil

Anvil editor → Create app → **Clone from GitHub** → this repo's URL. After pulling a version with new tables, accept the **Schema Mismatch** alert with "The schema of the source code is correct".
